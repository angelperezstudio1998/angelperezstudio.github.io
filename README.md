# Angel Studio

Portfolio website of Angel Studio, graphic design: logos, posters, tickets and brand identity.

Plain HTML, CSS and JavaScript, no build step. Published with GitHub Pages.

## Folders
- `index.html` home page (must stay at the root for GitHub Pages)
- `about/` about page
- `work/` category pages (logos, posters, tickets, media)
- `assets/css/style.css` all styles
- `assets/js/core.js` shared effects, then `home.js` / `about.js` per page
- `assets/fonts/`, `assets/images/` fonts and images

## Work on it locally
Open `index.html` in a browser. Links name their files (`about/index.html`), so they work straight from the computer and on GitHub Pages.
